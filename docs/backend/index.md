# Backend Documentation

Welcome to the backend documentation for the Grocery Fullstack project.

This folder contains backend-specific guides that explain the Java-based Spring Boot implementation, why files exist, how they work together, and how to understand the backend architecture.

## Contents

- `overview.md` — backend architecture and project layout
- `controllers.md` — REST endpoint controllers and routes
- `services.md` — business logic layer
- `repositories.md` — data access and JPA repositories
- `models.md` — domain entities, enums, and data objects
- `configuration.md` — Spring configuration classes and app settings
- `security-and-auth.md` — authentication, authorization, and session handling
- `audit-exception.md` — audit support and error handling
- `database-and-migrations.md` — PostgreSQL and Flyway migration details
