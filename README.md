# 🛒 Grocery Full-Stack Application

A full-stack grocery management application built using **React** and **Spring Boot**, designed with a clean modular architecture and Docker support.

---

## 🚀 Tech Stack

### Frontend
- React (Vite)
- JavaScript (ES6+)
- Tailwind CSS
- Axios

### Backend
- Spring Boot
- REST APIs
- JPA / Hibernate

### Database
- PostgreSQL

### DevOps
- Docker
- Docker Compose
- GitHub
